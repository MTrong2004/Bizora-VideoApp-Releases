Installation FAQ

How do I proceed if "Windows protected your PC" appears on first launch?

Because our standalone Windows installer is not commercially code-signed yet, Windows SmartScreen may ask for confirmation on first run. Click More info, then select Run anyway.

You can verify file integrity in PowerShell by confirming the SHA-256 hash matches the card on the right: 

certutil -hashfile Bizora-Video-Studio-Setup-0.1.0.exe SHA256
Will updating to a newer version delete my projects or connected channels?

No. Project workspaces, exported MP4 videos, and local channel tokens are stored in your user data directory, separate from the application binaries.

What are the minimum system requirements for Bizora Video Studio?

Requires Windows 10 or Windows 11 (64-bit) and an Internet connection when invoking AI tools, syncing publishing schedules, or checking for updates.
